# PALANART: внешняя авторизация

GitHub Pages обслуживает только статический клиент. Пароли проверяет Supabase Auth; секреты провайдеров хранятся в Edge Function Secrets.

Новые Edge Functions используют приватный PKCE verifier, одноразовые состояния в БД и проверку подписей/профиля на сервере. Привязка выполняется только после подтверждённого входа в целевой аккаунт. Для MAX предусмотрено подтверждение в исходном браузере.

Действующий backend недоступен; подготовленный код не означает проверенный OAuth-вход.

Подробности и необходимые настройки: [отчёт](docs/palanart-auth-recovery-2026-10-26.md).
