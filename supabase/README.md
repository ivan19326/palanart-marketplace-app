# PALANART Auth backend

Проект `oimwiyncaxffcijqtmzf`: схема профилей и 9 функций развёрнуты. Google OAuth настроен и проверен настоящими входом, выходом и повторным входом. SMTP и остальные четыре провайдера ещё требуют настройки.

Настройка, сохранение данных, callbacks и реальные проверки: [актуальный отчёт](../docs/palanart-auth-live-2026-11-13.md).

Новые функции используют `_shared/social-auth.js`; старый `_shared/marketplace-auth.ts` оставлен как исходный файл и не импортируется новыми точками входа.

Не применяйте SQL без изучения действующей схемы и резервного снимка. Секреты задавайте только в Edge Function Secrets.
