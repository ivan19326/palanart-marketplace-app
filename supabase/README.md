# PALANART Auth backend

С разрешения владельца создан проект `oimwiyncaxffcijqtmzf`. Схема профилей и 9 функций развёрнуты; SMTP и приложения провайдеров ещё требуют настройки.

Настройка, сохранение данных, callbacks и реальные проверки: [актуальный отчёт](../docs/palanart-new-backend-2026-11-12.md).

Новые функции используют `_shared/social-auth.js`; старый `_shared/marketplace-auth.ts` оставлен как исходный файл и не импортируется новыми точками входа.

Не применяйте SQL без изучения действующей схемы и резервного снимка. Секреты задавайте только в Edge Function Secrets.
